# 安装与使用

[文档目录](README.md) · [配置参考](配置参考.md) · [排查问题](排查与验证.md)

## 安装依赖

本项目依赖 Windows 的窗口截图接口。源码使用Python 3.10+语法，但不能据此推断当前全部固定依赖可在任何3.10+环境安装。建议先用Python 3.11/3.12独立环境；已有其他项目环境不要直接覆盖。

```powershell
git clone https://github.com/hey-three/han-card-tracker.git
cd han-card-tracker
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
python -m pip install -r requirements.txt
python -m pip check
python main.py
```

命令中的PyTorch组合与现有requirements一致，索引依据[官方旧版本安装说明](https://pytorch.org/get-started/previous-versions/)。不安装CUDA Toolkit并不等于没有CUDA运行依赖；GPU还取决于驱动与实际可用设备。无NVIDIA GPU时可在设置中选CPU，不把TensorRT视为必需项。

此次维护没有从零安装上述锁定环境。现有回归环境与requirements版本不完全相同，不能把已有测试结果当作固定依赖安装成功。遇到依赖或NumPy桥接错误，请保留完整错误与版本，见[排查与验证](排查与验证.md)；不要仅凭“安装完成”认定推理可用。

## 模型文件

仓库跟踪了YOLO11n/s/m模型子目录的best.pt及部分ONNX导出。模型列表按子目录扫描，不支持直接把best.pt放在weights根目录：

```text
yolo/weights/<模型名称>/best.pt
```

自定义模型需保留牌类映射，参见[训练约定](模型训练与拼图约定.md)。文件名中的imgsz_960是模型目录标签，不代表任何运行路线都使用960输入。n/s/m的速度与精度需要在本机测量，不直接宣称哪个“最准”。

## 记牌器界面排列

标题栏从左到右为设置、暂停/继续、重置、赞赏爱心，悬停可查看说明。点击爱心直接进入原有“设置 → 赞赏”，关闭后照常恢复检测；不会新建赞赏页面。页签流光或波动效果尚未加入。

“YOLO输入预览”的标题会显示此帧原图/拼图及实际像素尺寸。选择原图后，程序完整传入截图并等比补边；切换确认会清除旧预览，关闭设置并继续检测后等待新帧。若标题显示“桌面回退（需无遮挡）”，请把游戏窗口完整放在屏幕内，并将预览、设置等窗口移到游戏区域之外；目标最小化时不再保留旧帧冒充实时画面。

启动和切换模型/设备时，标题栏会显示“正在加载模型”“首次可能较久”；首次生成ONNX/TensorRT可能较久，后续可复用。原始PT不动，转换文件及校验记录位于该PT同目录，不再创建model_cache。关闭普通布局状态提示也不会隐藏加载提示；完成后恢复耗时/布局状态，失败则显示对应故障或设置错误。

在“设置 → 基本设置 → 界面排列”选择“上下排列”或“左右排列（长条）”。上/左区显示剩余牌数，下/右区显示出牌记录，两块使用相同底色，仅用一条细线隔开：上下排列是横线，左右排列是竖线，不使用外框或圆角。切换立即保存，重新打开继续使用，不清空当前牌局，也不切换游戏检测布局。

上下模式默认宽度由550缩到495逻辑像素，约缩小10%；左右模式默认900逻辑像素，两区等宽且随窗口一起按1:1伸缩；减少上下留白和行距，最低高度下限80逻辑像素，同时保证三行文字完整。实际尺寸随字体与DPI适配。出牌行简称“上、本、下”，取消前导空白；长历史可悬停查看。首次打开会在原生标题栏和布局生效后自动收拢一次，左右排列无需来回切换即可使用紧凑高度。之后再次显示窗口保留用户拖动调整的尺寸，主动切换排列时按新布局收拢。

普通布局提示显示在标题栏，不占底行。开启完整诊断后，队列/内存暂时拥堵只在标题栏显示“诊断暂缓”，悬停查看原因；恢复后回显布局提示，不再撑开底栏。识别故障、诊断暂停和日志写入错误也全部显示在顶部，悬停查看详情；识别服务故障时在标题栏出现“重启”按钮。主窗口没有底部状态栏。

出牌顺序遵循游戏画面：上面一行在前，下面一行接在后面，每行从左向右，不按牌点大小或标签字母排序。连续帧确认与防重复扣牌只比较牌点及张数，不因换行重排产生新出牌。布局方式下的二级配置区跟随系统窗口底色和中性边框，不再使用蓝色底纹。

## 选择布局

自动、手动分别记住上次使用的布局，点击模式立即使用对应布局；后台成功后才保存为下次启动项，失败恢复原模式和选择。不需要再点击额外的“应用”。没有布局时提示先新建，不会把另一模式的默认项当成已切换。更换检测布局会重置本局记录；上下/左右界面排列不会。

### 自动布局

在“设置 → 基本设置 → 自动布局”点击“新建布局”，选择游戏窗口并填写布局名称，再点“保存并使用”。下次直接从列表选择，无需重新找窗口；列表中的铅笔和垃圾桶分别编辑、删除。新建弹窗常规宽440逻辑像素，长标题省略显示但完整保存。建议开局前启用，等待上方底牌出现与非空手牌稳定。自动模式整图识别，不需要手工矩形；它适用于常见本家在下、两家在左右的界面，不能从中途画面恢复此前出牌。

### 手动布局

在“设置 → 基本设置 → 手动框选”中，点击“新建布局”，或在布局下拉列表点击某项右侧的铅笔图标编辑该项。垃圾桶图标用于删除，悬停分别显示“编辑”和“删除”，也可使用F2/Delete。列表会自动更新，不再需要刷新按钮。

再次编辑已保存布局时，会直接载入最近一次参考截图并显示已保存的五区，无需重新截图；原目标窗口未打开也可以查看和调整。编辑画布已直接显示五区边框；保存校验仅检查配置完整性与坐标，不会运行YOLO判断识别效果。旧布局此前没有缓存的，先补截一次即可。重新截图会替换旧图，同一窗口的框选按归一化比例保留。编辑器保持截图前的尺寸和位置，图片自动适应画布，仍允许手动调整窗口大小。

新建布局时先截取目标窗口，再依次框选五区：本家手牌、本家出牌、上家出牌、下家出牌、地主底牌。侧栏显示完成度，五区齐全后直接保存，保存时会检查五区、坐标和截图目标；已移除重复的“预览校验”步骤。编辑原布局后直接保存会覆盖该名称；改为其他已存在名称时会提示确认。

再次截取同一窗口会保留未保存的框选，截图尺寸变化时按比例调整。选择另一窗口后须重新截图，旧图不会误存到新窗口。截图失败保留草稿，退出时会提醒未保存修改。保存内容后，主窗口会重新提交当前布局的完整新坐标，后端确认后才重置显示；即使名称没改也会重新应用。两行出牌和大小王是否完整落在框内由用户确认；算法不向外扩边。

![五个区域的布局编辑示意](../images/layout_debug.png)

在“设置 → 高级设置 → 手动布局检测方式”选择拼图或原图。所有手动布局共用这一偏好，自动模式不受它影响。开局前拼图一直只取底牌和手牌，首次扣手牌后才换四区。

## 核对第一次计数

上方底牌连续两张截图有任意牌才开局，不比较牌面和张数；第二帧开始累计手牌稳定帧数，按设置确认非空合法手牌后扣一次。不要求17/20张，但稳定漏检会使初始化偏少，因此仍需核对识别完整性。开始记牌以后不因手牌数量变化自动补扣。

底牌持续消失满足帧数及时间阈值后，程序保留上一局数据等待下一局。新底牌出现才刷新。主窗口最上方的Windows原生标题栏同一行左侧提供设置、暂停/继续和重置图标，与右侧最小化、最大化、关闭按钮同行，不在下方再占一行；点击重置并收到后端确认后会清空牌局显示，适合明确需要重来时使用。

## 显示与排查开关

| 设置 | 用途 |
|---|---|
| 输出调试日志 | 终端输出区域结果与部分计时信息 |
| 完整诊断 | 按局保存实际YOLO输入/各调用标注、原图、状态与确认进度；队列/内存拥堵暂缓后自动恢复，磁盘故障暂停 |
| 诊断磁盘上限 | 默认1 GiB，可选0.1–1024 GiB（两位小数），限制全部诊断材料总量；空间不足清理已封口旧局，保护当前局 |
| 实时显示YOLO输入 | 独立窗口显示真正送入接口的原图或拼图 |
| 显示耗时 | 标题栏显示模型调用和整轮往返耗时 |
| 显示布局状态提示 | 在标题栏耗时后显示“等待画面”“确认手牌”“正在记牌”等短提示；悬停查看详情，正常提示不占底部一行 |

三项排查功能独立。关闭预览窗口或按Esc会保存关闭偏好；退出主程序只隐藏预览，不更改该偏好。完整诊断保存证据，自动回放尚未实现。

日常关键事件日志自动轮转。需要复现错误时短时开启完整诊断；设置页显示后台实际状态，暂缓与故障原因在顶部也始终可见，悬停查看详情。排除原因后关闭再开启会创建新会话，旧材料保持不完整标记。目录、容量和性能边界见[诊断记录](诊断记录.md)。
