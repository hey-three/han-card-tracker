# 配置参考

[文档目录](README.md) · [使用指南](使用指南.md)

用户配置为config/config.yaml，定义入口在config/settings.py。下表描述当前意义和典型值，**不是用户本机配置快照**；已有字段取文件值，缺省取源码默认值。

| 键 | 意义 | 典型值或缺省 |
|---|---|---|
| current_layout | 当前布局名称 | 已保存布局名 |
| window_layouts | 窗口标题、模式和归一化区域 | 见下面示例 |
| packed_inference | 所有手动布局使用拼图；false为原图 | 缺省true；自动模式始终整图 |
| detect_interval_sec | UI发起检测的采样间隔秒数 | 0.2，不代表推理200ms |
| reset_time | 底牌连续缺失的结束时间阈值 | 3.0，还需连续帧门槛 |
| frame_length | 同一牌组连续确认帧数 | 3 |
| device_choice | 设备路线 | cpu / cuda |
| yolo_model_name | weights下模型子目录 | yolov11s_imgsz_960 |
| yolo_confidence_threshold | YOLO置信度阈值 | 0.6 |
| yolo_iou_threshold | YOLO IoU阈值 | 0.45 |
| yolo_to_card_mapping | 模型类别到业务牌点的映射 | 自定义模型必须核对 |
| always_on_top | 窗口置顶 | true |
| show_played_cards | 显示出牌历史 | true |
| show_layout_status | 显示正常布局状态；故障仍显示 | 缺省true |
| show_current_screenshot | 实际YOLO输入预览 | 缺省false |
| show_timing | 标题栏显示耗时 | true |
| debug_mode | 终端调试输出 | 已提交示例false；代码缺省true |
| save_debug_images | 旧版同步原图/标注图落盘 | 缺省false |
| full_diagnostics | 后台逐帧诊断，保存所有模型调用和状态；与旧截图开关独立 | 缺省false |
| little_joker_shown / big_joker_shown | 出牌历史里的大小王显示字符 | 不改变模型类别或主界面牌名 |

## 布局示例

坐标为相对截图宽高的左、上、右、下，均在0～1范围。以下只是配置格式示例，不是推荐给所有软件的通用坐标：

```yaml
window_layouts:
  手动示例:
    window_title: 示例游戏窗口
    mode: manual
    layout:
      player_hand: [0.05, 0.70, 0.95, 0.90]
      player_played: [0.30, 0.45, 0.70, 0.65]
      opponent_left: [0.05, 0.25, 0.30, 0.50]
      opponent_right: [0.70, 0.25, 0.95, 0.50]
      landlord_cards: [0.35, 0.02, 0.65, 0.18]
  自动示例:
    window_title: 示例游戏窗口
    mode: auto
    layout: {}
```

旧布局未写mode时视为manual。自动生成的几何参照不写回YAML。手动框决定读取范围，不自动外扩。

## 保存与切换

- 只有主进程通过settings.save_*及config/store.py写盘；同目录临时文件与os.replace完成原子替换，成功后才改内存。
- 模型、设备、布局及手动检测方式先等后端成功回执再保存；后端失败保留旧配置，保存失败则停止检测并报告，不假报成功。
- 预览偏好是特例：先保存并更新窗口，再同步子进程传图开关，确保关闭选择不会因服务故障丢失。
- 布局切换、模型切换或显式重置可初始化牌局；仅切手动原图/拼图路线重建拼图缓存和尺度测量，不重扣已确认手牌。
- 冻结打包时可写运行目录与资源目录分别解析，不能把临时资源路径当作用户配置目录。

完整诊断的8帧、64MiB快照、256KiB单帧JSON和1GiB磁盘限额为代码常量DiagnosticLimits；不是可任意传入update_settings的配置项。详见[诊断记录](诊断记录.md)。
