## Windows双版本发布

使用Python 3.11：CPU环境安装requirements-cpu.txt和requirements-build.txt；CPU/GPU环境安装requirements.txt（CUDA 12.1索引）和requirements-build.txt。不把GPU环境仅改名当成CPU包。

```powershell
python scripts/build_release.py --flavor cpu --version v4.3.3
python scripts/build_release.py --flavor cpu-gpu --version v4.3.3
```

分别在对应环境执行。产物在artifacts/packaging/v4.3.3/<类型>/dist/HanCardTracker/，包内模型与默认配置在_internal，首次启动复制干净配置到EXE同级config。默认CPU、原图检测，预览和完整诊断关闭；不修改维护者的个人配置。

验收：`HanCardTracker.exe --verify-bundle <报告JSON路径> --device cpu`；CPU/GPU版还需`--device cuda`。该命令启动Qt主窗口，等待真实Worker就绪及正常退出，再在spawn进程逐个调用模型。它不是完整游戏准确率或无显卡机器验收。

验收后使用对应环境执行`python scripts/build_release.py --flavor <类型> --archive-only`生成ZIP，过滤验收日志、用户配置和机器缓存。完整分发EXE及配套文件，每个GitHub资产小于2GiB；发布说明列明版本、依赖、模型、校验值和验证范围。先核对新包可下载，再移除指定旧Release，保留未要求删除的历史Git标签。
