# 斗地主自动布局

[文档目录](README.md) · [手动拼图](拼图自适应与检测方式.md) · [计数规则](斗地主记牌设计说明.md)

## 适用范围

设置 → 基本设置 → 自动布局，选择目标窗口即可保存mode:auto及空layout。运行时根据当前画面学习几何，不按游戏名称查固定区域表；生成参照不写回配置。

自动模式始终整图推理，适用于常见本家在下、对手在左右、底牌在上方的三人斗地主。建议从开局前启用，不能从中途画面还原先前历史，不宣称兼容所有软件。

## 分组与归属

1. YOLO框按截图尺寸归一化，顶边聚行，行内空隙拆牌组，单张也是牌组。
2. 同侧/列对齐、尺度相近的相邻行先合并，再按整组归属。不能先把短末行判给本家，随后以不同玩家身份阻止合并。
3. 上方底牌先发布存在性，任意一张可开局；下方任意非空合法手牌按FRAME_LENGTH稳定后学习几何。几何initial只是定位通知，不直接绕过Tracker扣牌。
4. 左家用左边、右家用右边、本家用中心及第一行顶边作锚点；长牌组跨中线不能逐张拆给两家。
5. 初始桌面位置从手牌和窗口相对几何推导，底牌不是必要位置锚点，但底牌存在性仍是业务门禁。中央翻牌动画不视为上方底牌到位。
6. 候选过远、前两名接近、同区出现不相容牌组时返回未知；不强行选择最近区域。近期手牌减少和此前稳定的独立本家出牌可阻止错误并行合组。

阈值集中于core/auto_layout.py，尺度来自牌框自身。它是几何先验与在线锚点，不是经过所有皮肤测量的模板。

## 空区与未知

| 返回 | 含义 |
|---|---|
| 有键且非空 | 已知区内有牌 |
| 有键且空列表 | 当前明确为空 |
| 没有键 | 归属或画面不可靠 |

Controller通过known_regions传给Tracker；未知中断未确认序列，不抹已确认历史或制造重复出牌所需的空区过渡。底牌消失的帧数和时长判断遵循[牌局生命周期](斗地主记牌设计说明.md)。

## 重新定位与回归

截图长宽比相对参照改变超过5%只重新校准几何并保留本局记录。底牌变化牌点不换局；复杂重排、持续有底牌的切局或不确定期间丢失出牌，可能需要在下一局重置。

tests/fixtures/right_wrapped_play.json保存一张实际截图的模型框，回归覆盖首次八加二、末行单张、左右镜像、移动、抖动、换行重排和六帧确认。该截图初始手牌不足，测试使用补充模拟牌建立几何；不是重建原局真实开局，也不是完整动画验收。
