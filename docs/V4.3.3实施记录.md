# V4.3.3实施记录

[文档目录](README.md)

用户于2026-10-30确认以下方案，要求基于E盘最新源码实现、回归，并经V4.3.3分支合并main。当前运行契约见[自动布局](自动布局设计说明.md)及[记牌规则](斗地主记牌设计说明.md)。

## 第1项：自动底牌区域独立定位

- 横向固定为目标游戏窗口截图的15%～85%，即居中70%，不再依赖本家手牌中心或宽度。
- 纵向高度动态学习。初搜上限为窗口高度25%，按牌框中心筛选；取检测框下沿加半个框高为高度提议，封顶25%。连续两帧提议差不超过屏高3%时取较大值确认，单帧转校准/跟踪不能重复计数。
- 学习复用现有底牌两帧确认，不要求三张齐全，也不增加额外YOLO调用。
- 确认后本局不因少牌、空帧或未知中断收缩。截图尺寸改变、新局、布局切换及显式重置重新学习；等比尺寸变化仅重学底牌框，不清牌账。
- 预览框应准确显示实际用于判断的范围，不能再以未表达实际限制的宽泛搜索框误导用户。
- 顶部计数栏误识别及超出搜索范围的布局仍属适用边界，不能把区域学习称作适配所有软件。底牌判断已移除手牌中心、宽高及相对位置依赖。

## 确认保留的开局时序

开局前仅见手牌不累计初手确认；首次见底牌也不累计；连续第二帧有底牌时进入已开局状态，该帧手牌才算第1帧。初手按设置FRAME_LENGTH连续多重集一致后扣一次，不要求17/20张；底牌不比较牌面/张数。本次不提前缓存或回补定位期间的对手出牌。

## 同步纳入的本地改动

- YOLO预览单字标签：上、下、本、底、手；原图画区域，拼图仅标裁片名称。默认宽495逻辑像素，设置打开时后台识别继续。
- 同位置检测通常保留最高置信度，J与大小王冲突优先大小王；诊断保留原始调用及过滤结果，不补扣本家出牌。
- 启动时已选模型目录或best.pt缺失，按目录名排序选第一个有best.pt的模型，UI与推理快照同名。不在导入/子进程阶段改写个人配置；损坏权重或非法输入配置仍明确报错。
- 纳入当前模型目录与输入配置更新，生成文件的机器校验元数据、诊断、日志及用户参考截图不发布。
