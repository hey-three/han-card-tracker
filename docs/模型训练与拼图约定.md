# 当前模型训练与拼图约定

当前契约以 [V4.3.1设计与验证](V4.3.1设计与验证.md) 为唯一详细入口。

- 自动布局整图；手动布局在首次扣牌前选底牌+手牌，扣牌后选三家出牌+底牌。
- 当前统一宽高8:5、宽768×高480，动态推理参数(H,W)=(480,768)。一个模型混合原图和两阶段拼图，不要求分别训练多个模型。
- 依据三张实图的YOLO单牌框中位高度缩放：底牌1.652110、手牌0.703958、上家1.000212、下家1.002385、本家出牌0.836045；不是按用户区域框尺寸缩放。大小王竖框单列。
- 首次扣牌不要求17/20张，按V3非空稳定手牌扣一次；底牌任意一张即开局，底牌持续消失后保留旧显示至下一次开局。
- 原图和拼图训练数据需先按牌局分集合，再作等比填边和Tile标注变换；普通Ultralytics训练imgsz是单整数，使用rect批次并检查真实shape，不能把推理的二元组直接塞给普通训练。
- 旧640方图和五区方案为历史对照，不在当前正式手动链路使用。既有静态引擎保留导出形状，需另行导出矩形才能获得相应网络计算收益。
- 没有启动训练；没有以三张图的成功代替完整实战、GPU或Android性能验收。
