## 排查顺序

| 现象 | 先看什么 |
|---|---|
| 无法启动/服务故障 | 状态栏错误、终端堆栈、Python和包版本、权重文件；修正后重启识别 |
| pip找不到torch的cu121包 | Python版本、官方cu121索引及requirements，不仅看Python语法最低版本 |
| 有图但不开局 | 实际YOLO输入是否有上方底牌、区域是否正确、置信度、手牌是否非空稳定 |
| 原图能识别、拼图不行 | 高级设置切换对照；核对用户框、切口、初值和实际输入，不能假设程序会扩框 |
| 两行出牌分错玩家 | 保存对应原图和最终标注，说明归属、首次出现还是已有锚点；附布局模式 |
| 本家打牌没有再减 | 先核对统计口径；本家初始手牌已扣，本家出牌不应重复扣 |
| 结束后还显示旧记录 | 设计如此，下一次底牌出现开局才刷新 |
| 预览或保存缺帧 | 区分未传图、无可靠结果、未建活动目录、容量上限和真实保存失败 |
